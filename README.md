# Оценка качества вина

Приложение для домашнего задания 3. Вино рекомендуется, если вероятность
экспертной оценки не ниже 7 достигает выбранного порога.

## Окружение и запуск

Python 3.13.12. Точные версии библиотек указаны в `requirements.txt`.
Модель сохранена с scikit-learn 1.6.1.

Откройте терминал в папке `wine_app`. Для нового окружения:

```bash
python3.13 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Если окружение уже создано и библиотеки установлены:

```bash
.venv/bin/python -m streamlit run app.py
```

Откройте адрес из терминала, обычно http://localhost:8501.
Для остановки нажмите Control+C в терминале.

## Файлы

- `app.py` — интерфейс и предсказания.
- `model.joblib` — обученный пайплайн StandardScaler и LogisticRegression.
- `config.json` — порог, выбранный по максимуму F1 на валидации.
- `test.csv` — тестовые признаки и ответы в столбце target.
- `requirements.txt` — точные версии зависимостей.
- `example_wines.csv` — пример пяти вин для проверки загрузки CSV.

Модель в приложении не обучается. Исходный порог: 0.2688887270064323.
Все вкладки используют общий порог из боковой панели.

## Вкладки

1. «Оценка одного вина»: 11 числовых полей и переключатель красного/белого вина.
   Диапазоны и медианы взяты из test.csv. Выводятся вероятность и решение.
2. «Модельные метрики»: матрица ошибок, precision, recall, F1, ROC- и PR-кривые
   с точками текущего порога.
3. «Пакетное предсказание»: загрузка CSV, вероятности, решения и скачивание
   результата. Проверяются отсутствующие столбцы и некорректные значения.
4. «Что выучила модель»: отсортированные коэффициенты после масштабирования
   и пояснения наиболее сильных положительных и отрицательных коэффициентов.

## Формат CSV

Файл в UTF-8 с запятой или точкой с запятой в качестве разделителя.
Каждая строка — одно вино. Обязательные столбцы:

```text
fixed_acidity,volatile_acidity,citric_acid,residual_sugar,chlorides,free_sulfur_dioxide,total_sulfur_dioxide,density,pH,sulphates,alcohol,is_red
```

Порядок столбцов произвольный. Приложение выставляет порядок модели.
Значения числовые, без пропусков и бесконечностей. Для is_red: 0 — белое,
1 — красное. Столбец target в загружаемом файле не нужен.
Пример можно скачать во вкладке приложения или взять из example_wines.csv.

## Кэширование: задание 4.5

Streamlit выполняет скрипт сверху вниз при изменении виджета.

- `load_model` использует `st.cache_resource`: модель является общим ресурсом.
  Возвращается один сохранённый объект без повторного чтения joblib при каждом
  изменении порога. Модель используется только для предсказаний.
- `load_test_data` использует `st.cache_data`: результатом является таблица.
  Streamlit сохраняет данные и возвращает копии, подходящие для обработки.
- `get_test_probabilities` использует `st.cache_data`: массив вероятностей
  зависит от признаков, но не от порога. При движении ползунка выполняются
  сравнение с порогом и расчёт метрик, а не predict_proba на тестовой выборке.
  Аргумент `_model` начинается с подчёркивания, поэтому не хешируется.
- Вероятности загруженной CSV-таблицы также кэшируются отдельно.

Без декоратора кэширования `joblib.load` заново читал бы модель с диска
при каждом перезапуске скрипта, добавляя ненужную работу и замедляя интерфейс.

Пути строятся от `Path(__file__).parent`, поэтому чтение файлов не зависит
от текущей рабочей директории.

## Публикация: задание 4.6

1. Создайте GitHub-репозиторий и загрузите содержимое папки wine_app.
   Папки .venv и .idea загружать не нужно.
2. Откройте https://share.streamlit.io и подключите GitHub.
3. Выберите Create app, свой репозиторий, ветку и файл app.py.
   Если загружена сама папка wine_app, путь будет wine_app/app.py.
4. В Advanced settings выберите Python 3.13 и запустите деплой.
5. Проверьте работу приложения по выданной ссылке и доступ для проверяющего.
6. Добавьте фактическую ссылку в ноутбук и README.

Публикация выполняется отдельно после локальной проверки.
